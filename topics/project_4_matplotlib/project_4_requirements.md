## Overview

In Project 03, you used Chart.js to present your survey results on a web page. In this project, you will use **Python and Matplotlib** to analyze and visualize the same data.

Your program will read data from a CSV file, calculate statistics, display results, and generate charts. The goal is to demonstrate how Python can automate data analysis and visualization.

**Important:** Your program must generate the charts from the CSV data. Changes to the CSV file must be reflected in your statistics and charts when the program is run again, without modifying the Python code. In otherwords, if you change data values in your CSV file and re-run your code, the graphs and statistics will be updated using the new data values.

## Project Requirements

### 1. Read Data from a CSV File

- Use the CSV data file from your previous projects.
- Read the CSV file using Python's `csv` library.
- Store the data in parallel Python lists.
- Use a `while` loop to copy data from the CSV file into your lists.
- Convert numerical data to `int` or `float` as appropriate.
- Do not manually enter survey responses into your Python program.

Refer to **Sample Project 04 (`project04.py`) – Section 1** for an example of reading CSV data into parallel lists.

### 2. Process and Summarize the Data

Use Python lists, loops, conditional statements, and calculations to summarize the data needed for your charts.

Your program must:

- Display the total number of survey responses.
- Calculate and display the counts or frequencies needed for charts involving categorical data.
- Calculate and display averages or other appropriate statistics for numerical data, when applicable.
- Display the results in the Python console with clear descriptions.
- Calculate chart values from the CSV data rather than hard-coding the results.

Refer to **Sample Project 04 – Sections 2, 3, and 4** for examples of using `while` loops to calculate and display statistics.

### 3. Create Charts Using Matplotlib

- Recreate at least three charts from Project 03 using Python's Matplotlib library.
- Use appropriate chart types such as pie, column/bar, line, or other Matplotlib charts.
- Generate the charts using values calculated from your CSV data.
- Include descriptive chart titles and appropriate labels.
- Use colors and other formatting properties to make the charts attractive and easy to read.
- All charts must be generated by a single Python program.

The Matplotlib charts do not need to look identical to your Chart.js charts, but they should communicate the same results.

Refer to **Sample Project 04 – Sections 5, 6, and 7** for examples of creating and formatting charts using Matplotlib.

### 4. Test with Updated Data

Your program must automatically recalculate results when the CSV data changes.

1. Run your program using your original CSV file.
2. Change a response or add a new response in the CSV file.
3. Run the Python program again without modifying the Python code.
4. Verify that the console statistics and appropriate charts reflect the updated data.

### 5. Program Documentation and Organization

Include comments at the beginning of your Python program identifying:

- Program filename
- Author
- Date
- Description of the program

Organize your program into clearly identified sections using comments, similar to the sample project:

1. Read the CSV file into parallel lists.
2. Summarize data for Chart 1.
3. Summarize data for Chart 2.
4. Summarize data for Chart 3.
5. Display Chart 1.
6. Display Chart 2.
7. Display Chart 3.

You may organize your program differently if needed, but your code should be easy to read and understand.
