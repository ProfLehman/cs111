

# Common File Formats

Different file formats store data in different ways. The format used can affect the **file size**, **image quality**, **compression**, and which programs can open the file. Image formats often use either **lossy compression**, which reduces file size by permanently discarding some data, or **lossless compression**, which reduces file size while preserving all of the original image data.

## Common Image Formats

### JPEG

**JPEG (Joint Photographic Experts Group)** is one of the most common formats for photographs and other images containing many colors and gradual changes in color. JPEG primarily uses **lossy compression**, which reduces file size by permanently removing some image information. Higher compression produces smaller files but may also reduce image quality. JPEG files are commonly identified by the `.jpg` or `.jpeg` file extension. JPEG is well suited for photographs but is generally not the best choice for diagrams, text, or images that require a transparent background.

### PNG

**PNG (Portable Network Graphics)** uses **lossless compression**, meaning that the image can be compressed and later restored without losing image data. PNG is commonly used for screenshots, diagrams, logos, and other images containing text or sharp edges. PNG also supports **transparent backgrounds**, making it useful for graphics used on websites and in presentations. PNG files typically use the `.png` file extension. For photographs, PNG files are usually larger than comparable JPEG files because no image information is discarded.

### BMP

**BMP (Bitmap Image File)** is an older image format originally developed for Microsoft Windows. BMP files represent images as a grid, or **bitmap**, of individual pixels. BMP images are typically stored without lossy compression and may be completely uncompressed, resulting in very large file sizes compared with formats such as JPEG or PNG. BMP files typically use the `.bmp` extension. Because of their large size, BMP files are less commonly used for sharing images on the web.

### HEIC

**HEIC (High Efficiency Image Container)** is a modern image format commonly used by Apple devices such as the iPhone and iPad. It typically uses **lossy compression** to provide high-quality photographs while using less storage space than comparable JPEG files. This allows a phone to store more photographs without substantially reducing image quality. HEIC files usually use the `.heic` extension. Although support for HEIC has increased, some programs and devices may convert HEIC images to JPEG for greater compatibility.

### WebP

**WebP** is a modern image format developed for use on the Web. It supports both **lossy and lossless compression**, allowing image creators to choose between smaller file sizes and exact preservation of image data. WebP also supports features such as **transparent backgrounds** and animation. WebP images often provide smaller file sizes than comparable JPEG or PNG images, which can help web pages load more quickly. WebP files typically use the `.webp` extension.
